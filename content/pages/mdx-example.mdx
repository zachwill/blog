This is an example post written in **MDX** format, which means you can use React components alongside your Markdown content.

## Regular Markdown Works

All your usual Markdown features work perfectly:

- Lists
- **Bold text**
- _Italic text_
- [Links](https://example.com)
- `Code snippets`

```javascript
// Code blocks with syntax highlighting
function greet(name) {
  return `Hello, ${name}!`;
}
```

> Blockquotes work too!

## Interactive Elements

With MDX, you can add interactive elements:

<div style={{
  background: 'linear-gradient(45deg, #007aff, #00d4ff)',
  color: 'white',
  padding: '20px',
  borderRadius: '8px',
  textAlign: 'center',
  margin: '20px 0'
}}>
  This is a styled React component directly in your Markdown!
</div>

## Benefits of MDX

1. **React Components**: Embed interactive elements
2. **Styling**: Use inline styles or CSS classes
3. **Data Visualization**: Add charts, graphs, and interactive demos
4. **Future-Proof**: Easy to migrate existing Markdown posts

## How to Use

1. Create files with `.mdx` extension in `_posts/`
2. Use the same frontmatter format as Markdown posts
3. Write regular Markdown content
4. Add React JSX elements where needed

The build system automatically detects and processes both `.md` and `.mdx` files!
